安裝

  1. 雙擊 雷虎練唱台2.3.3.exe（從 GitHub 下載的檔名是 LeihuLiantai-2.3.3-Setup.exe）。已經裝過舊版的，直接安裝新版即可，歌曲庫和設定會保留。1.6.7 起，有新版本時畫面上方會出現「有新版 x.y.z，點這裡更新」，按兩次確認後會自動下載、核對檔案並安裝，裝好自動重新開啟（處理中的工作會中斷）。
  2. 如果出現藍色的「Windows 已保護您的電腦」，按「其他資訊」，再按「仍要執行」。這是因為安裝程式沒有付費的數位簽章，不是病毒警告。
  3. 選安裝位置（預設即可，不需要系統管理員權限），按「安裝」。
  4. 如果這台電腦裝過雷虎練唱台，會先詢問：
    • 裝過且完整：「是」更新（沿用已下載的套件和模型，最快）；「否」全新重裝（清除舊的程式和套件後重新下載）。
    • 上次安裝沒有完成：「是」接著安裝並自動修復不完整的檔案（建議）；「否」清除上次留下的檔案後重新安裝。
    兩種方式都會保留歌曲庫、錄音、設定和已下載好的模型。
  5. 會跳出一個黑色視窗，自動下載 Python、AI 套件和模型。視窗裡有總進度條，下載時會顯示已下載的大小和速度，視窗標題也會顯示百分比。有 NVIDIA 顯示卡時會自動裝顯示卡加速版。依網路速度大約 15–40 分鐘，期間不要關掉這個視窗。
  6. 完成後桌面和開始選單會出現「雷虎練唱台」。
安裝中途斷網、當機或被關掉時，重新執行安裝程式並選「是」即可：已下載的部分會從斷點接著下載（PyTorch 下載完會核對檢查碼），不完整的 Python、套件和模型會被偵測出來並自動重裝。安裝紀錄在安裝資料夾的 logs\install.log。

匯入歌曲

開啟後的第一個畫面是「歌曲庫」，匯入方式：

  • 音訊匯入框：點歌曲庫上方的「音訊匯入」框選擇檔案，或把音訊檔拖進視窗，一次可以多首。
  • 音訊匯入按鈕：一次可以選多首。支援 MP3、WAV、FLAC、OGG、M4A、AAC、OPUS、WMA。
  • YouTube：貼上影片網址，按「下載並分析」。請只下載你有權使用的內容。
  • 批次加入：按 YouTube 欄旁的「批次加入」，每行一首，可以混著輸入影片網址、歌單網址（加入歌單裡每一首）或「歌手 歌名」（到 YouTube 搜尋第一筆）。也可以從 Excel 複製「歌手、曲名」兩欄貼上，或按「匯入 Excel／CSV」選 .xlsx／.csv 檔。按「查詢」後確認清單（可以勾選、用 ▲▼ 調整順序），再按「加入下載佇列」。搜尋到的歌請確認是原唱版本，伴奏版沒有主唱，分析不出旋律。
  • 從歌單表單匯入：Excel／CSV 照下面「建議的匯入表格格式」整理，曲名、歌手、KEY、語言和 YouTube 網址會一起帶入。

處理會依序排隊。歌曲庫上方排隊中的歌可以用 ▲▼ 調整順序，或按「取消」。

匯入後會自動依序處理：分離主唱／合音／伴奏、分析主唱旋律，最後在背景到線上歌詞網站找同一首歌的歌詞，自動套用最符合的第一個版本（網站有時間軸、長度也相同時直接用網站的時間軸；否則依主唱的聲音位置對齊）。排第一的版本歌名和長度都對不上時不會自動套用，歌詞先留白，可以在練唱畫面的「搜尋線上歌詞」自己挑。自動辨識歌詞預設不執行（準度不穩，也比較慢），想用的話到設定勾選「匯入時自動辨識歌詞」，或對單首歌用「重新處理 → 只重新辨識歌詞」。進度會顯示在歌曲庫上方，處理時可以繼續練別首歌。處理太久或卡住時，可以按進度旁的「停止」，已經完成的步驟（例如分軌、旋律）會保留；失敗的訊息可以按「✕」關閉。

分類與搜尋

  • 按「＋ 新增分類」建立自己的分類，例如「中文歌」「日文歌」「練習中」。
  • 選了某個分類後再匯入，歌就會直接放進這個分類。
  • 曲名與歌手：每首歌大字顯示曲名，下面小字是歌手和預設 KEY。用 YouTube 下載的歌會自動從影片資訊拆出曲名和歌手（拆不出歌手時留空），YouTube 原本的標題在曲名上停一下就會看到。按「編輯資訊」可以修改曲名、歌手和預設 KEY。
  • 排序：搜尋框左邊可以選「最新加入」「依曲名」「依歌手」；依歌手時同一位歌手的歌會排在一起。
  • 每首歌右邊的分類選單可以隨時換分類。選取某個分類後可以改名或刪除；刪除分類不會刪歌，歌會移到「未分類」。
  • 右上的搜尋框可以用歌名、歌手或一段歌詞找歌，多個關鍵字用空白隔開。

歌名旁的標籤：AI 分軌代表用 AI 模型分離；聲像分軌代表 AI 分離沒有成功，改用比較粗略的方式，可以按「重新處理」再試；清唱代表原曲本身就是沒有伴奏的純人聲。清唱的歌第一次開啟時，會自動用歌名搜尋線上歌詞讓你挑選。

練唱畫面

琥珀色長條：原唱的音符，上面標有音名 琥珀色細線：原唱實際的音高，看得出滑音和抖音 藍線：你的聲音（麥克風或錄音） 紅線：你和原唱差超過 50 音分（約四分之一個全音）的地方

卷軸的音域依整首歌的旋律固定，高音和低音都看得到，播放時不會上下跳動。右上角會顯示目前的目標音，和你偏高或偏低多少。

控制列的「旋律」可以切換顯示方式：原聲曲線是原唱實際的音高，看得出滑音、轉音、抖音；音符區塊只顯示整理過的音符，比較容易看出每個字該唱哪個音；原聲＋區塊兩者疊在一起。

卷軸下方的歌詞有三行：上一句、正在唱的、下一句。正在唱的那句會一直顯示到下一句開始，就算歌詞時間有點誤差也不會一閃就過。右上角的 A−／A＋ 可以調整這三行的大小。

直播歌詞（去背）

給 OBS 等直播軟體用的歌詞畫面：只有歌詞、背景透明，會跟著練唱台的播放同步顯示與逐字上色。

  1. 在練唱畫面按「直播歌詞」，選行數（1／2／3／5 行）、字級、位置、對齊、字體、上色顏色。
  2. 按「複製網址」。
  3. 在 OBS 新增「瀏覽器」來源，網址貼上，寬 1920、高 1080。背景本來就是透明的，不用另外去背。
  4. 在練唱台播放歌曲，OBS 上的歌詞就會跟著走。練唱台要保持開著；回到歌曲庫時直播畫面會清空。

直播軟體不支援瀏覽器來源時，背景改選「綠幕」，用瀏覽器開啟後擷取視窗，再加「色度鍵」濾鏡去掉綠色。改了設定要重新複製網址貼到 OBS。

混音

每一軌都可以單獨調音量。四個快速設定：

  • 原曲：原本的歌
  • 卡拉OK：關掉主唱，保留合音與伴奏
  • 練唱：主唱調小，加上旋律導引音，最適合對音準
  • 只聽主唱：只留主唱，適合抓咬字和換氣

每首歌的 KEY、速度、混音會自動記住。

音量標準化（預設開啟）：每首歌會量好響度（LUFS，和 YouTube、Spotify 用的標準相同），播放時自動調到差不多大聲（-16 LUFS），不用每換一首就調電腦音量。主唱、合音、伴奏的每一種開關組合都分別量過，播放時依你目前開著的音軌（音量 50% 以上算開著）計算，所以切到卡拉OK（關掉原唱）時，每首歌的伴奏也會一樣大聲；拉桿照你設的比例作用，切換時音量會平順變化。舊歌會在背景慢慢補量（有歌在處理時暫停），還沒補到的歌第一次打開時多等 2～3 秒。原始檔不會被改動；取消勾選就是原本的音量。小聲的歌最多加大 12 dB，快要爆音時會自動壓住。旋律導引音和你的錄音不受影響。

直播模式

直播時用的精簡版面：按畫面右上角的「直播模式」切換，再按一次回到完整版面（會記住上次的模式）。左邊是歌曲清單，右邊是大字歌詞（固定一次顯示五行）和操作列，其他功能（背景處理、直播歌詞、每句評分）照常運作。

  • 歌曲清單：點一首就開始；上面有分類、搜尋、抽歌、排序。
  • 待唱清單：在歌曲右邊點「＋」加進清單，按「下一首」載入第一首。一首唱完會自動載入下一首（不會自動播放，按播放才開始）；快唱完時會先在背景準備好下一首的 KEY 版本，切歌不用等轉換。
  • 操作列：播放／暫停、進度、KEY、原曲／卡拉OK、音量（只調歌曲，不影響導引音和麥克風）、歌詞即時調整（這句對準、下一句對準、±0.1 秒，可選「後面的句子一起移動」，自動儲存）。
  • 原唱只給我聽：操作列的「原唱只給我聽」開啟後，原唱和導引音只從「自己聽的裝置」（你的耳機）播出，觀眾那邊（「音樂輸出裝置」）只有伴奏和合音。先到設定把兩個裝置選成不同的：只有一副耳機時，「音樂輸出裝置」可以選免費的虛擬音效線 VB-Cable，再讓 OBS 用「音訊輸入擷取」收 VB-Cable。注意 OBS 的「應用程式音訊擷取」會把練唱台兩路聲音都收進去，要改用裝置擷取。耳機沒接上或裝置沒設好時，原唱會先靜音，不會送給觀眾。音量標準化會以觀眾聽到的（沒有原唱）為準。
  • 歌詞待修：直播中發現歌詞不準，按歌詞工具列或操作列的「歌詞待修」（Ctrl+Alt+F）先標起來，不用當場處理。歌曲庫會多一個「歌詞待修」分類，下播後一次處理；再按一次取消標記。
  • 建議重新匯入歌詞：歌曲重新分離（升級高品質、最高品質、細修、直播後補做）後，練唱台會比對目前歌詞在重新分離前後和歌聲位置的吻合度；分離後明顯變差時歌曲會標「⚑ 建議重新匯入歌詞」，也會出現在「歌詞待修」分類，打開歌曲時會提醒。重新搜尋線上歌詞、貼上或調整歌詞後，提醒自動消失。已經用高品質模型處理過的歌不會被重複處理。
  • 搜尋線上歌詞：操作列的「搜尋線上歌詞」會開一個對話框，和完整版面「歌詞」面板裡的搜尋一模一樣（LRCLIB、網易雲、酷狗），點一個版本就套用。
  • 前奏倒數：第一句之前、或間奏 5 秒以上之後，下一句開口前 3 秒在歌詞上方顯示 3、2、1（完整版面也有）。
  • 直播歌單：一首歌播放超過 30 秒就記下來（不限直播模式），按「直播歌單」可以一鍵複製（含時間和 KEY）、產生 YouTube 章節、回顧過去的場次。距離上一首超過 6 小時會自動當成新的一場，也可以手動開始新的一場。
  • 直播歌詞的曲目資訊：在「直播歌詞」設定的「曲目資訊」選位置，OBS 畫面角落會顯示「♪ 歌名 － 歌手 KEY +2」。改了設定要重新複製網址貼到 OBS。

旋律譜圖片

把旋律和歌詞畫成一頁頁的圖片，只能開圖片的時候（手機相簿、平板、印出來）也能對著練。在旋律下方的工具列按「旋律譜圖片」（或「歌詞」面板的「匯出旋律譜圖片…」）。

  • 每句歌詞一列，太長自動換列。上面是旋律：方塊越高音越高、橫向是時間，跟練唱畫面的卷軸一樣；下面是歌詞，每個字放在開始唱的位置。
  • 標示：簡譜（1～7，上面加點高八度、下面加點低八度，#4 表示升 4）、音名（C4＝中央 C）或兩者都標。簡譜的「1」預設自動判斷，也可以自己指定。
  • 版面：手機直式（1080×1920，一頁約 6～10 句，用相簿左右滑）或 A4（可以直接列印）。
  • 預設套用目前的 KEY。
  • 圖片存在「下載\雷虎練唱台\歌名 旋律譜（手機／A4）」資料夾，匯出完會自動打開這個資料夾；每次匯出會覆蓋同一個資料夾裡的舊圖片。
旋律是從原唱自動分析的，沒有拍子資訊，所以是用時間位置排版，不是正式的五線譜或有節奏的簡譜。逐字位置用的是目前歌詞的逐字時間（沒調過的句子用自動分配的位置）。

錄音評分

  1. 戴上耳機（避免伴奏被麥克風收進去，影響評分）。
  2. 每句評分（測試中）：歌詞工具列的「每句評分」開啟時，開麥克風唱，每唱完一句旋律區上方會跳出 PERFECT／GREAT／GOOD／MISS，附這句的命中率與連續幾句沒 MISS（COMBO）；錄音停止時會顯示這次各評價的句數。評價看兩件事：原唱有旋律的地方你唱到幾成，以及唱的音有幾成落在原唱 ±50 音分內（不分八度，換音時早晚 0.15 秒內都算對）。有歌詞時一句歌詞算一句，沒有歌詞時依旋律的停頓分句；跳轉後前面沒唱到的句子不評。
  3. 在「麥克風」選單選要用的輸入裝置（例如 GoXLR、USB 麥克風），再按「開啟麥克風」，卷軸上會即時畫出你的音高。第一次開啟後選單才會顯示裝置名稱；之後會記住你的選擇。
  4. 看「音量」表調整大小：唱歌時音量條大多在綠色、偶爾到黃色最好；碰到紅色就是太大聲。可以拖「增益」調整，或按「自動調整」後用平常練唱的音量唱幾句，程式會自動調到適合的大小。音量過大時會出現紅字提醒，錄音也會自動壓住避免爆音，讓評分更準。
  5. 想直接從唱的地方開始，按「跳過前奏」跳到第一句前 5 秒；勾選「自動」後每次從頭播放都會自動跳過。
  6. 錄音中跳過前奏、點卷軸換位置或 A-B 循環回到起點時，程式會把前一段收尾、從新位置接著錄新的一段，評分時間才對得上。不到 8 秒的片段（例如前奏）會自動丟掉；開 A-B 循環錄音時，每唱完一輪會各存成一筆。
  7. 建議 KEY：唱的時候程式會比對你和原唱的音高（男女差一個八度不算）。如果你大多數的音都固定比原曲高或低 2 個半音以上，代表這個 KEY 不適合你的音域，「我的演唱」會出現「建議改成 KEY X」和一鍵套用的按鈕。錄音評分完成後也會再給一次建議。
  8. 錄音太多時，按錄音列表上方的「選取多筆」，勾選後可以一次刪除。
  9. 按「錄一次」：會從 A 點（沒設就從目前位置）開始播放並錄音。唱完按「停止」。
  10. 幾秒後出現分數。命中率是你的音落在原唱 ±50 音分內的比例（換音時早晚 0.1 秒內都算對）；平均偏差是正數代表偏高、負數偏低。

評分完全在你的電腦上進行，不需要連網或 Claude。系統會自動對齊錄音延遲。男生唱女生的歌（或相反）差一個八度也沒關係，會自動換算。點錄音紀錄可以把你的音高曲線疊在卷軸上，並列出最需要練的三句，點句子就會跳到那裡。

匯出與分享演唱

點一筆錄音紀錄，按「匯出／分享這次演唱」。程式會把你的歌聲和合音、伴奏混在一起（拿掉原唱和導引音），用的是錄音當時的 KEY 和速度，時間也會自動對齊。

  1. 調整音量：打開時程式會依你的歌聲和伴奏的響度，自動算好建議音量（歌聲比伴奏大約大 3 dB）。「你的歌聲」「合音」「伴奏」三個拉桿可以再各自微調（拉到最左是靜音），「恢復建議音量」會重新計算。「人聲美化」會去掉低頻雜音、讓音量比較平均；「殘響」可以選不加、輕、中、大廳。
  2. 試聽：按「▶ 試聽」會從你開始唱的前 2 秒播放，可以拖時間軸。播放中拖音量拉桿會即時聽到變化；切換人聲美化或殘響會重新處理幾秒後接著播放。
  3. 匯出範圍：預設是整首歌（伴奏和合音從頭到尾，你的歌聲放在錄音的那一段）；也可以選「只有錄音的段落」。
  4. 選格式（可複選）：
    • MP3／WAV 音訊：只要聲音時使用，WAV 是無損格式。
    • 直式影片 9:16：1080×1920，畫面有歌名、旋律線條（原唱音符和你的音高）、正在唱的歌詞，適合 IG／FB Reels、Threads、X。
    • 成績卡圖片：1080×1350，有命中率、平均偏差、整段旋律對照圖和還可以更好的句子，適合一般貼文或限時動態。
  5. 按「匯出」，檔案會存到「下載\雷虎練唱台」資料夾。
  6. 發佈：按 Facebook、Instagram、X 或 Threads，會用瀏覽器打開該平台，同時打開檔案所在的資料夾；把檔案拖進去，貼上程式幫你準備好的貼文文字（可以先修改再按「複製文字」）即可。
分享到社群前請注意：伴奏和合音是原曲的一部分，平台可能會因為版權偵測把影片靜音、限制地區或下架。直播回放、短片的音樂規定以各平台為準。

歌詞

歌詞是 LRC 格式，每行前面的 [分:秒] 是這句開始的時間。自動辨識難免有錯字，可以用下面幾種方式修正：

  • 第一句開始時間：整首歌詞都早了或晚了一點時（例如你的版本前奏比較長），在歌詞面板最上方調整「第一句開始」：播放到第一句開口的地方按「對準目前位置」，或用 ±0.1／±0.5 秒微調，也可以直接輸入時間。後面每一句和逐字時間都會一起移動，並自動儲存。「依歌聲自動校正」：歌詞內容對、但整體早了或晚了好幾秒（例如 MV 版前奏比較長）時按這個，會依主唱開口的位置自動找出要移多少秒（最多 ±60 秒）。套用有時間軸的線上歌詞時，也會自動做這個檢查。
  • 歌詞順序不會變：按「對準」或 ± 調整時，一律以你調整的那一句為準；前面的句子如果因此排到它後面（例如前面錯太多），會被往前推到它之前，後面的句子同理往後推，順序永遠不變。
  • 中段以後才不準：前面都對、從某一句之後開始延遲或提早時，在「第一句開始」下方按：「這句以後對準目前位置」（歌詞比歌聲早時，把目前顯示的這句對到播放位置），或「下一句以後對準目前位置」（歌詞慢半拍時，歌手開口唱、畫面還停在上一句時按）。那一句和後面每一句會一起移動，前面不變，自動儲存。
  • 直接修改：在文字框改好後按「儲存歌詞」。
  • 匯入歌詞檔：按「匯入歌詞檔」選 LRC、SRT 或 TXT 檔。有時間的直接使用；純文字（每行一句）在辨識結果可靠時依辨識的時間對上每一句，不可靠時依主唱有聲音的段落估計時間。UTF-8、Big5（繁體）、GBK（簡體）編碼都能讀，簡體會自動轉成繁體（只轉字形，不改用詞）。
  • 跟拍打點：先把正確歌詞貼進文字框（每行一句，不用時間），按「跟拍打點」，播放時每唱到新的一句就按 空白鍵。
  • 用 Claude 對齊：展開「貼上正確歌詞」，貼上歌詞後按「用 Claude 對齊」，Claude 會參考辨識結果和旋律自動填上每句的時間，並依旋律把每個字放到對應的音上（需要 API 金鑰，見下一節）。對齊時會請 Claude 直接回傳時間、不先長篇思考，費用比以前低，長歌詞也不會被截斷。
  • 逐句調整開始時間：每一句都有時間欄位。播放到某句開頭時按「對準」，或用 −／＋ 每次調 0.1 秒，也可以直接輸入時間。按 ▶ 會從那句前 1 秒開始播放。按「開新視窗逐句調整」會另開一個練唱台自己的、可以自由縮放的視窗，字體跟著視窗大小調整、長句自動換行，可以放在旁邊邊唱邊調：每句都有 ▶、對準、±0.1 秒，上方有播放／暫停和 ±5 秒（空白鍵也能播放／暫停）；勾「後面的句子一起移動」時，對準和 ± 會連同後面每一句一起移動。在這個視窗的調整會自動儲存。
  • 自動分配每個字的時間：已有每句時間的歌詞，可以一鍵依旋律音符分配每個字的時間，再用「調整」微調。
  • 線上歌詞比對：匯入歌曲時，程式會用歌名（原文和轉成簡體各一次）到 LRCLIB、網易雲音樂和酷狗音樂搜尋。找到的版本會列出歌名、歌手、長度、有沒有時間軸和開頭幾句，讓你選一版使用。排序主要看歌名和歌曲長度；辨識結果可靠時，才另外參考和辨識結果的相似度。
  • 套用線上歌詞：有時間軸且長度相符的，直接用網站的時間；有時間軸但長度不同的（不同版本），依主唱開口的位置把整份時間軸對齊；只有文字的，辨識可靠時依辨識的時間對上，不可靠時依主唱有聲音的段落估計（建議再用「對準目前位置」微調）。網易雲和酷狗的簡體歌詞會自動轉成繁體（只轉字形，不改用詞）。有時間軸的候選版本會標「和歌聲吻合 N%」：拿它的時間軸和這首歌主唱開口的位置比對（長度不同的版本先對齊再比）。75% 以上通常就是同一個版本，50% 以下多半是翻唱、現場版或不同剪輯，不會自動套用；排序也會優先放吻合度高的。
  • 辨識結果和線上歌詞分開保存：歌詞面板上方會顯示「目前使用」哪一份，可以按「改用辨識結果」或「改用線上歌詞」切換，切換不會覆蓋另一份。調整線上歌詞的時間後儲存，會存回線上歌詞那一份。之後重新辨識歌詞，也不會蓋掉你選用的線上或匯入的歌詞。
  • 辨識不準確時自動留白：辨識完成後，程式會檢查辨識的把握程度、有沒有同一句一直重複、有唱歌的地方有沒有辨識出字。判斷不可靠時，歌詞會先留白，歌曲庫顯示「建議找線上歌詞」，練唱畫面也會提示，按「搜尋線上歌詞」即可。想看辨識結果的話，按「仍然使用辨識結果」。
  • 這首的辨識語言：預設依設定（建議「自動判斷」）。全域設定是中文、但偵測到明顯是日文、英文等其他語言時，會自動改用偵測到的語言。也可以在歌詞面板替這首歌指定語言，再按「重新辨識歌詞」。
  • 手動搜尋：展開「搜尋線上歌詞」，輸入歌名和歌手再搜尋。

常見問題

歌很多、一次處理好幾十首，可以快一點嗎？

2.1.1 起有三個做法：

  • 前後兩首重疊處理（自動）：上一首分離完、在分析旋律和存檔時，下一首就先開始分離，整批大約快一成多，品質不變。
  • 常唱的歌先做（自動）：按「升級舊歌」時，最近開過、直播唱過、有錄音、設過 KEY 的歌排在前面，冷門的歌放後面。
  • 閒置時兩首同時分離（設定裡打開，實驗性）：沒在直播時兩首同時分離，可以再快約兩到四成。需要顯示卡記憶體 10 GB 以上才會啟用（8 GB 的顯示卡實測反而比較慢），那首重新排回最前面。

怎麼把歌單給觀眾看？

歌曲庫上方按「匯出歌單」，可以選三種格式：

  • 網頁：給觀眾看的點歌清單，可以搜尋、依分類切換。檔案直接傳到 Discord 或放上網路空間，點開就能看；可以自訂標題、要不要顯示 KEY。
  • Excel（.xlsx）：分類、歌手、曲名、KEY 四欄，可以自己排版、篩選。
  • 練唱台歌單（.csv）：備份或換電腦用，在「批次加入」匯回會依 YouTube 網址自動重新下載、處理。

預設只列處理好、能唱的歌；也可以只匯出目前的分類。檔案存在「下載\雷虎練唱台」。

直播結束後想整理唱過的歌？

歌曲庫上方或直播模式的「直播歌單」可以回顧這一場和過去的場次。不管是不是直播模式，一首歌播放超過 30 秒就會記下來；距離上一首超過 6 小時才算新的一場，所以同一段時間唱的歌都會在同一場。「顯示方式」選「YouTube 章節時間戳」，把開台時間改成影片開始的時間，就會產生可以直接貼到 YouTube 影片說明的章節（00:00 開場、每首歌開始的時間）。也可以存成文字檔，或匯出 Excel（時間、直播時間、曲名、歌手、KEY）。按「開始新的一場」時，上一場會保存起來。不想留的歌可以勾選後按「刪除勾選的歌」，整場不要的話按「刪除這一場」。

硬碟空間不夠、或要換電腦？

設定裡的「儲存位置」可以把歌曲庫（和可選的 AI 模型）搬到別的磁碟：

  • 選好新位置後，練唱台會先複製過去、逐一核對檔案大小，全部正確才改用新位置；中途失敗或按停止，會繼續用原本的位置。
  • 舊的那份會留著。確認新位置一切正常後，再到設定裡按「刪除舊位置」釋放空間。
  • 搬移期間處理佇列會暫停，暫時不能操作歌曲，搬完自動恢復。
  • 換電腦或用外接硬碟：把搬移後的資料夾（裡面有 library、models）整個複製到新電腦或接上外接硬碟，在練唱台的搬移視窗選那個資料夾，按「改用這裡現有的歌曲庫」就能直接使用，不用重新處理。也可以用「匯出歌單 → 練唱台歌單」，到新電腦批次加入重新下載。

搜尋找不到歌？

搜尋框左邊可以選搜尋範圍：「搜歌名、歌手」（預設，最準）、「搜歌詞」（只記得一句歌詞時用，結果會顯示符合的那句）、「全部都搜」（歌名歌手符合的排前面，只有歌詞裡有的放在後面另外標出）。繁體、簡體互相找得到，空格和標點可以不打；打錯字或少打字時會列出歌名相近的歌。搜尋會找全部分類，目前分類的歌排在前面。

想先處理某一首歌？

還沒處理好的歌（旋律未完成、還沒下載）在歌曲庫會有「優先處理」按鈕；已經處理好、但想先升級成高品質分離的歌，用「重新處理… → 優先處理」。按了之後這首會排到處理佇列最前面，下一首就處理它。處理清單裡排隊中的歌也可以按「⤒」直接移到最前面。

處理到一半要開台怎麼辦？

按處理清單上方的「全部暫停」（或 Ctrl+Alt+P）：處理中的那首會在下一個進度點停下、讓出顯示卡，排隊中的歌都先不開始，重開程式後也維持暫停。錄音評分、KEY 轉換照常。下播後按「繼續處理」，做到一半的那首會從頭重做。就算沒按，偵測到 OBS、VTube Studio 時背景工作也會自動停下（見下一題）。

練唱台閒著的時候會不會佔顯示卡記憶體？

2.1.1 起不會。人聲分離、旋律分析、歌詞辨識這些要用顯示卡的工作，改在另外的「顯示卡處理程式」裡做，練唱台本身（介面、播放、KEY 轉換）完全不載入顯示卡的運算環境。處理完 30 秒沒有新工作，處理程式就會自己結束，顯示卡記憶體全部還給系統；在工作管理員裡會看到「專用 GPU 記憶體」回到開練唱台之前的水準。按「停止」或「全部暫停」時，處理程式會立刻結束。直播中處理程式會用較低的優先順序執行，KEY 轉換也只用一半的 CPU 核心。

直播中背景處理會不會影響直播？

不會。預設開啟「直播中暫停背景處理」（設定裡可以關）：偵測到 OBS、Streamlabs、XSplit、vMix 或 VTube Studio 在跑，或練唱台的直播模式開著時：

  • 背景工作先停：升級分離、細修、最高品質處理、壓縮這類會吃滿顯示卡、又不急的工作會停住（做到一半的會讓出顯示卡，下播後重做），歌曲庫上方會顯示「直播中，背景工作已暫停」；直播軟體關掉後自動繼續。
  • 顯示卡被其他程式佔滿時也一樣：就算沒有開直播軟體，只要顯示卡記憶體剩不到 3.5 GB、或已經被其他程式用得很滿（遊戲、錄影、NVIDIA 即時重播等），也會跟直播中一樣先暫停背景工作、新的分離改用 CPU，顯示卡空出來後自動恢復。
  • 直播中匯入照常：觀眾點歌、臨時加歌、按「優先處理」或重新處理的歌照常處理，但改用輕量模型（標準分離），而且只用 CPU、不碰顯示卡：直播軟體和 VTube Studio 佔著顯示卡時，顯示卡運算會被擠到幾乎停住，改用 CPU 才不會卡在 2%。下播後練唱台會自動用顯示卡＋高品質模型重新分離一次（歌詞、錄音不動）。
  • KEY 轉換、錄音評分照常（錄音評分的音高分析直播中也改用 CPU），直播中換歌照常。

真的要在直播中做背景工作，按「直播中也照常處理」可以暫停偵測一小時。

伴奏裡還聽得到人聲、主唱軌有鼓聲

設定裡的「人聲／伴奏分離品質」選高品質（有顯示卡預設就是）會改用 BS-Roformer 模型，伴奏殘留的人聲和主唱軌殘留的樂器都明顯減少，旋律分析與歌詞辨識也跟著變準；處理時間約是標準模型的兩倍，第一次使用會背景下載約 640 MB。已經處理過的歌不會自動重做，到設定按「用高品質人聲模型重做全部歌曲」會把還沒用新模型處理的歌排進佇列（歌詞、錄音、KEY 設定都保留），或對單首歌用「用最高品質人聲分離重新辨識」。

合唱歌（例如 S.H.E）旋律斷斷續續、歌詞漏句

多人輪流唱的歌，分離模型常把某位成員唱的整句歸到「合音」，主唱軌就斷斷續續。在練唱畫面的歌詞面板按「合唱模式（多人輪流唱）」（或歌曲庫的「重新處理…」選單），旋律分析與歌詞辨識會改用主唱＋合音一起分析，跟著當下最大聲的那個人，不用重新分軌、很快。再按一次可以改回只用主唱。合唱模式不改變播放的分軌：卡拉OK 時想完全沒有人聲，把「合音」也拉到 0。

一個主唱、後面和聲很多的歌，可以改用「用最高品質人聲分離重新辨識」：用高品質模型、最精細的設定重新分離主唱與合音，再重新分析旋律、重新辨識歌詞（最慢，有顯示卡約一般處理的兩倍時間）。兩種方式都不會覆蓋你正在用的線上或匯入歌詞。

辨識出「優優獨播劇場」「Thanks for watching」之類的句子

這是語音辨識在間奏、沒有人聲的地方產生的「幻覺」（來自訓練資料裡影片字幕的片頭片尾）。程式會自動過濾；舊的辨識結果打開時也會自動清掉。

分離後主唱還是有伴奏的聲音

AI 分離無法做到百分之百乾淨，混音比較厚的歌會有殘留。可以在設定把人聲分離模型換成 model_bs_roformer_ep_317_sdr_12.9755.ckpt（目前最準，但比較慢，第一次使用會下載），再對那首歌「重新處理 → 全部重做」。

旋律線斷斷續續

氣音、和聲很重或伴奏殘留多的段落，音高比較難判斷，會出現空白。這不影響播放和評分的其他段落。

合音多的歌，旋律亂跳、間奏也有旋律

代表主唱和合音沒有分乾淨。到「設定」確認「主唱／合音分離品質」是「自動」或「高品質」，再對這首歌選「重新處理 → 全部重做」。

辨識歌詞時卡住

按歌曲庫上方進度旁的「停止」。分軌和旋律會保留，之後可以在練唱畫面貼上或搜尋歌詞，或用「重新處理 → 只重新辨識歌詞」再試一次。

YouTube 下載失敗

YouTube 常改版，程式失敗時會自動更新下載工具再試一次。仍失敗的話，從開始選單執行「雷虎練唱台 修復與更新」。私人影片、會員限定或需要登入的影片無法下載。

錄音顯示「沒有偵測到歌聲」

表示錄音裡幾乎沒有聲音，或錄的那段原唱沒有旋律。請確認「麥克風」選單選對裝置、唱歌時音量表有在動（可以按「自動調整」）。這筆錄音可以直接刪除或按「重新評分」。

麥克風沒有反應

確認 Windows 設定 → 隱私權與安全性 → 麥克風，有允許桌面應用程式使用麥克風；並確認預設錄音裝置是你要用的那支。

出現錯誤視窗、程式卡住或功能不正常

從開始選單執行「雷虎練唱台 修復與更新」。它會關閉程式、檢查並修好套件，再自動重新開啟。問題還在的話，把安裝資料夾裡 logs 資料夾的檔案提供給開發者。

有 NVIDIA 顯示卡，安裝時卻說沒偵測到

先更新 NVIDIA 顯示卡驅動程式（建議 570 版以上），再從開始選單執行「雷虎練唱台 修復與更新」。還是不行的話，執行「雷虎練唱台 修復（強制使用顯示卡加速）」，會直接安裝顯示卡版。偵測過程記錄在 logs\install.log。

搜尋歌詞顯示「無法連到歌詞網站」

1.2 已修正 1.1 會一直出現這個訊息的問題。如果還是出現，確認網路能開啟網頁；防火牆或防毒軟體可能擋住了程式連網。詳細原因記錄在 logs\lyrics.log。

練唱時旋律區太小或歌詞太擠

拖曳旋律和歌詞中間的分隔條，就能調整兩邊的高度比例；雙擊分隔條還原預設。

出現「no kernel image is available」或「顯示卡和 PyTorch 版本不相容」

顯示卡比較舊（GTX 10 系列以前），和安裝的顯示卡加速版本不相容。程式會自動改用 CPU 繼續處理（比較慢）。執行開始選單的「雷虎練唱台 修復與更新」，會改裝支援這張顯示卡的版本，之後就能用顯示卡加速。

沒有 NVIDIA 顯示卡可以用嗎

可以，所有功能都一樣，只是分離和辨識比較慢：一首 4 分鐘的歌大約 5–15 分鐘（有顯示卡約 1 分鐘）。

歌曲存在哪裡？怎麼備份

在安裝資料夾的 library 資料夾（預設是 %LOCALAPPDATA%\LeihuLiantai\library，可以貼到檔案總管的網址列開啟）。備份這個資料夾即可。

解除安裝

Windows 設定 → 應用程式 → 找到「雷虎練唱台」→ 解除安裝。過程中會問你要不要保留歌曲庫；選「否」就只移除程式，歌曲和錄音會留下來。
